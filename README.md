# Automation Practice with Java

This repository is a hands-on sandbox for practicing Java fundamentals and Selenium-based web automation. Designed for clarity-first learning, it separates core Java logic from automation workflows to help learners build confidence step by step.

## 📁 Folder Structure

- `src/` – Contains all Java source code  
  - `basic.datatype` – Demos for primitive types, operators, user input  
  - `automation.tests` – *(Coming soon)* Selenium-based test cases  
- `.gitignore` – Excludes IDE and build artifacts

## 🚀 Getting Started

1. Clone the repo:git clone https://github.com/abhigithb/automation-practice-java.git


2. Import into Eclipse:
- File → Import → Existing Projects into Workspace  
- Select the `src/` folder only (ignore `.classpath`, `.project`, etc.)

3. Run any demo from `basic.datatype` to test setup.

## 🛠 Prerequisites

- Java JDK 8 or higher  
- Eclipse IDE (or any Java IDE)  
- Git (for version control)
